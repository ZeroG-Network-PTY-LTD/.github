### 👋 ZeroG Network

We're a small South Africa–based dev team building tools for the Minecraft server community — a NeoForge essentials mod, the web dashboard that goes with it, and a standalone desktop app for setting up and running modded servers without the usual hassle.

[![Discord](https://img.shields.io/discord/709351422088708196?color=7289da&label=Discord&logo=discord&logoColor=white)](https://discord.gg/dUGAQF2Mga)

#### 🛠️ Projects

| Project | What it is |
|---|---|
| [**NeoEssentials**](https://github.com/ZeroG-Network-PTY-LTD/NeoEssentials) | A comprehensive, config-driven essentials mod for Minecraft NeoForge servers — 50+ commands, GUI tools, and a real-time web dashboard. |
| [**NeoEssentials-Dashboard**](https://github.com/ZeroG-Network-PTY-LTD/NeoEssentials-Dashboard) | The web dashboard that pairs with NeoEssentials — players, kits, warps, economy, and live server status. |
| [**StellarServerForge**](https://github.com/ZeroG-Network-PTY-LTD/StellarServerForge) | A native desktop app for setting up, launching, and maintaining modded Minecraft servers (Forge/NeoForge/Fabric/Quilt/Vanilla) — no terminal menus, no hand-editing JVM flags. |

#### 💬 Support

Got a bug, a question, or an idea?

- If it's specific to one of the projects above, open an issue in that project's repo — it reaches the right maintainers directly.
- Otherwise, open an issue right here in [**.github**](https://github.com/ZeroG-Network-PTY-LTD/.github/issues/new/choose) — our general support entry point for anything that doesn't belong to a single repo.
- Or just come say hi in [Discord](https://discord.gg/dUGAQF2Mga) — most day-to-day support happens there.
