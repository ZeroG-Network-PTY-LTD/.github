# .github

This repository serves two purposes for [ZeroG Network](https://github.com/ZeroG-Network-PTY-LTD):

1. **General support** — the entry point for bugs, questions, and suggestions that don't belong to
   a specific project repo (see [NeoEssentials](https://github.com/ZeroG-Network-PTY-LTD/NeoEssentials),
   [NeoEssentials-Dashboard](https://github.com/ZeroG-Network-PTY-LTD/NeoEssentials-Dashboard), and
   [StellarServerForge](https://github.com/ZeroG-Network-PTY-LTD/StellarServerForge) for project-specific
   issues instead).
2. **Org-wide defaults** — the [`profile/README.md`](profile/README.md) here renders as our
   [organization profile](https://github.com/ZeroG-Network-PTY-LTD), and the
   [issue templates](.github/ISSUE_TEMPLATE) here act as the fallback for any org repo that doesn't
   have its own.

## Opening a request

Click **New issue** and pick the template that best matches your request. If your issue is specific
to a particular project, consider opening it in that project's repo instead so it reaches the right
maintainers directly.

You can also reach us in [Discord](https://discord.gg/dUGAQF2Mga) — most day-to-day support happens there.
